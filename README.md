# Chrono city



A modern personal website built with Vite, React, React Router, TypeScript, and TailwindCSS.

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open the local URL printed by Vite to view the site.

## Building for Production

```bash
npm run build
npm run preview
```

## Testing

```bash
npm test
```

## Customization

1. Update your information in `src/pages/about.tsx`
2. Add your projects to `src/pages/projects.tsx`
3. Update contact details in `src/pages/contact.tsx`
4. Customize colors in `tailwind.config.ts`

## Tech Stack

- [Vite](https://vite.dev) - React build tooling
- [React](https://react.dev) - UI library
- [React Router](https://reactrouter.com) - Routing
- [TypeScript](https://www.typescriptlang.org) - Type safety
- [TailwindCSS](https://tailwindcss.com) - Styling
- [Lucide Icons](https://lucide.dev) - Icons
